1. システム概要

--------------------------------------------------------------------------------

国土交通省「ドローン情報基盤システム2.0 (DIPS 2.0)」における無人航空機の

飛行許可・承認申請手続きを効率化するための支援Webツール。



航空法および航空局の「無人航空機の飛行に関する許可・承認審査要領」に準拠した

申請文面の自動生成、審査要件に応じた選択肢の切り替え、DIPS 2.0画面構成に

沿った入力ナビゲーションを提供する。





2. 設計方針とアーキテクチャ

--------------------------------------------------------------------------------

(1) 完全シングルファイル構成 (Single File Application)

    - 外部ビルドツール（Node.js / Webpack等）を一切不要とし、HTML/CSS/JS を

      単一の HTML ファイル (index.html) に集約。

    - オフライン動作および端末ローカルでの直接実行に対応。



(2) 外部依存ライブラリ

    - スタイリング: Tailwind CSS (CDN版)

    - アイコン表示: Font Awesome 6 (CDN版)



(3) セキュリティ・データ管理

    - クライアントサイド完結型。

    - 外部サーバーへの入力データ送信は行わず、個人情報や業務上の機密を保護。

    - navigator.clipboard API によるクリップボード連携（非対応環境向けに

      document.execCommand のフォールバックを実装）。





3. サポートする申請区分

--------------------------------------------------------------------------------

ユーザーは以下の4つの申請モードをラジオボタンで切り替え可能:



(1) 期間更新・再申請（デフォルト）

    - 前回の包括申請が満了することに伴う再申請。

    - 前回許可番号の引き継ぎ文面、直近1年間の無事故・無違反状況を反映。



(2) 新規包括申請

    - 1年間・日本全国を対象とした新規の包括的許可・承認申請。



(3) 変更申請

    - 既存の許可内容に対し、機体追加、操縦者追加、基準変更等を行う申請。



(4) 個別申請

    - 飛行日時（特定日＋予備日）および飛行場所（住所・施設名）を個別指定する申請。





4. 画面入力パラメータ仕様

--------------------------------------------------------------------------------

[申請種別]

  - renew: 期間更新・再申請

  - comprehensive_new: 新規包括申請

  - modify: 変更申請

  - individual: 個別申請



[日時指定]

  - 包括・更新・変更: 

    * 飛行開始予定日 (カレンダー選択 / type="date")

    * 終了日は開始日から「1年後 - 1日」を自動計算

  - 個別申請:

    * 飛行開始日時 (type="datetime-local")

    * 飛行終了日時 (type="datetime-local")

    * 予備日 (type="date")



[前回許可情報] (renew / modify 選択時に表示)

  - 前回許可書番号 (テキスト入力: 例「東空運第XXXX号」)

  - 直近1年間の事故・インシデント有無 (セレクトボックス: なし / 報告済)



[飛行目的]

  - 空撮 / 点検 / 測量 / 農林水産業 / 自然観測・研究 / 事故・災害対応 / その他



[飛行形態 (チェックボックス)]

  - 人口集中地区 (DID)

  - 人又は物件から30m未満

  - 夜間飛行

  - 目視外飛行



[安全確保体制・立入管理措置 (チェックボックス)]

  - 補助者の配置 (周囲監視・第三者立入制限)

  - 排他区画の明示 (コーン・パイロン・トラバー・立入禁止看板等)

  - フェールセーフ機能 (自動帰還RTH・通信遮断対策)

  - 機体安全装備 (プロペラガード・衝突回避機能)



[運用基準・操縦者情報]

  - 風速中断基準 (初期値: 5m/s)

  - 操縦実績時間 (初期値: 10時間以上)

  - 緊急連絡先 (テキスト入力: 氏名・電話番号)





5. DIPS 2.0 出力ナビゲーションおよび文面生成ロジック

--------------------------------------------------------------------------------

DIPS 2.0 の入力画面構成に合わせて5つのステップ枠に分離出力:



[ステップ1: DIPS 申請作成方法・地図提出要否]

  - 選択した申請区分に応じたDIPS操作ルートを案内

    * 包括/更新: 「過去の許可・承認情報を利用して申請」等

    * 地図要否判定: 包括申請時は「不要（日本全国指定）」、

      個別申請時は「必須（DIPS上でのポリゴン描画またはKMLアップロード）」



[ステップ2: 飛行の目的・理由（自由記述欄）]

  - 包括/更新/個別に応じた業務背景、年間対応の必要性、前回許可番号、

    無事故実績を組み合わせた申請理由書テキストをリアルタイム生成。



[ステップ3: 安全を確保するために講じる体制（自由記述欄）]

  - 操縦体制（実績時間）、機体点検・運用基準（風速リミット）、

    立入管理措置（補助者配置・パイロン等による排他区画設定）、

    フェールセーフ・安全装備の有無を箇条書き形式で構造化生成。



[ステップ4: 飛行マニュアル選択指針]

  - 「補助者配置」の有無に応じ、航空局標準マニュアル②が適用可能か、

    独自マニュアルの添付が必要かを動的に判定・注意喚起。



[ステップ5: 緊急連絡体制・インシデント対応]

  - 緊急連絡先、119番/110番初動対応、航空局事故等報告機能への

    報告義務を定めた規定文面を生成。





6. 今後の拡張予定（ロードマップ）

--------------------------------------------------------------------------------

1. ローカルストレージ連携

   - 操縦者名、機体登録記号、許可番号等のブラウザ内自動保存・復元。

2. ブラウザ拡張機能 (Tampermonkey / Chrome Extension) への移植

   - DIPS 2.0 申請画面のDOM要素へ各項目を1クリックでオートフィルする機能。

3. 独自マニュアルひな形出力機能

   - 補助者なし目視外飛行等に対応した立入管理措置規程テキストの書き出し。
